# TikTok For You Page Clone

A complete, modern, fully responsive TikTok-style "For You" page website built with pure HTML, CSS, and Vanilla JavaScript.

## Features

- Full-screen vertical video feed with smooth snap scrolling
- Autoplay / pause videos using Intersection Observer
- Mute by default (like real TikTok)
- Double-tap to like with heart burst animation
- Single tap to play / pause
- Right sidebar with:
  - Profile picture + Follow button
  - Like button with count
  - Comment button
  - Share button
  - Bookmark / Save button
  - Spinning music disc
- Bottom navigation bar (Home, Friends, Create, Inbox, Profile)
- Caption expand on click
- Loading spinner
- Mobile-first + Desktop responsive
- Dark theme matching TikTok

## How to Run

1. Extract the zip file
2. Open `tiktok-foryou.html` in any modern browser (Chrome, Firefox, Edge, Safari)
3. That's it! No server needed.

## Notes

- Videos are loaded from free public sources (Google sample videos + MDN)
- Some videos may take a few seconds to load depending on your internet
- Best experienced on mobile or by resizing browser to mobile size
- Works offline after first load (except videos)

## Customization

You can easily change the videos by editing the `videos` array inside the `<script>` tag.

Enjoy!
